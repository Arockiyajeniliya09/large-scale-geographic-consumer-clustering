# Large-Scale Geographic Consumer Clustering & High-Dimensional Visualizations

## 📌 Project Overview

This project applies Machine Learning techniques to analyze real estate data and identify distinct housing market segments. Using K-Means clustering, properties are grouped based on selected features to reveal meaningful patterns that can support business decisions, market analysis, and regional planning.

---

## 🎯 Objective

- Analyze real estate property data
- Perform data preprocessing and feature selection
- Group similar properties using K-Means Clustering
- Visualize the clustering results
- Generate insights for housing market segmentation

---

2. Clean missing values

6. Visualize the clusters
7. Analyze the results

## 📈 Machine Learning Algorithm

The project uses the **K-Means Clustering** algorithm to divide housing data into multiple consumer market segments based on property characteristics.
